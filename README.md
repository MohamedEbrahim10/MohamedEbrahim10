[![Courier App](https://img.shields.io/badge/Courier_App-tracking--app-02569B?style=flat-square&logo=github)](https://github.com/ahmedmohsen087/tracking-app)

A synchronized **two-app logistics ecosystem** — consumer e-commerce marketplace + courier driver tracking — built with Clean Architecture and BLoC/Cubit.

| Capability | Implementation |
|:---|:---|
| **Over-The-Air Patching** | Automated Shorebird Code Push via GitHub Actions (`shorebird patch android`) — zero-downtime hotfixes |
| **Background GPS Tracking** | Headless location service (`flutter_background_service`) streaming coordinates to Firestore when app is minimized/killed |
| **Live Route Rendering** | Dual mapping (`google_maps_flutter` + `flutter_map`) with OSRM routing, polylines, and dynamic ETAs |
| **Payments & Notifications** | Stripe Gateway with 3D Secure + Firebase Cloud Messaging for order status alerts |
| **Offline Resilience** | `dio_cache_interceptor` + Hive store for offline-first catalog caching; `dart_either` for error handling |
| **CI/CD Quality Gates** | Unit tests (`bloc_test`, `mockito`), lint checks, branch/PR validation, Firebase App Distribution |

Tech: Flutter · Dart · Firebase (Firestore, FCM, Crashlytics) · Shorebird · Stripe · Google Maps
